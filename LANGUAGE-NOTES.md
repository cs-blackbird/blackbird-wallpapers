# Language labels

Everyday word labels, not invented translations or ceremonial phrases. Pté: buffalo/herd; thípi: house/dwelling; wówapi: book/writing; wóuŋspe: lesson/teaching; mní: water; mahpíya: sky; čháŋ: tree; íŋyaŋ: stone; othúŋwahe: town. The source materials use differing orthographies; these are labels rather than claims about dialect preference.

Sources: https://lakhota.org/wp-content/uploads/2014/11/Level-1-Teachers-Guide.pdf and https://lakhota.org/wp-content/uploads/2014/11/Level-2-Teachers-Guide.pdf

All site identifiers in this edition are fictional.

NATIVE code uses authentic written word tokens with invented nonlinguistic operators, not translated Lakota prose. Reading words right-to-left is not implied: the postfix pane only aligns syntax to the right. Numerals waŋží, núŋpa, yámni, tópa, záptaŋ follow the LLC word-find teaching sheet: https://www.lakhota.org/downloads/pdf/Word%20Finds.pdf
